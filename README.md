# Astro-Go

Bewertung von 1 bis 10, ob sich das Aufbauen der Seestar S50 Pro heute Nacht lohnt.

- Wetterdaten von [Open-Meteo](https://open-meteo.com/) (CC BY 4.0): MET Nordic, ICON-EU, ECMWF IFS, UK Met Office, GFS
- Bewertet Bewölkung (tief/mittel/hoch, Konsens der Modelle), Dunkelheit, Mond, Niederschlag, Nebel, Tau, Böen und grob das Seeing
- Sonne und Mond werden im Browser berechnet

Live: https://robert-tech-byte.github.io/astro-go/

`index.html` ist eigenständig (die Logik ist eingebettet). `astro-core.js` enthält dieselbe Logik zum Testen mit Node.
